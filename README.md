Token launch radar — ranks pre-token DeFi protocols by implied value from their own snapshot figures (TVL, 7-day growth, time running with no token), and gives every protocol a concrete farm plan with costs and times. Covers all 40 watchlist protocols plus 163 more launch candidates.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
